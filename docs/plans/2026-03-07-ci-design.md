# CI Pipeline — GitHub Actions for Private Repo

**Goal:** Automated quality gates on every PR to main — tests, PII file scan, and dependency security audit.

**Architecture:** Single GitHub Actions workflow with three parallel jobs triggered on `pull_request` to `main`. Supplemented by Dependabot for passive dependency update alerts.

## Workflow: `.github/workflows/ci.yml`

**Trigger:** `pull_request` targeting `main`

### Job 1: `test` — pytest

- Checkout repo
- Set up Python 3.12
- Install dependencies from `requirements.txt`
- Run `pytest` (including `agents/lib/tax_computations.py` self-test)

Fails if any test fails.

### Job 2: `pii-scan` — File Type Blocker

- Checkout repo
- List all files in the PR diff
- Check for blocked extensions: `.pdf`, `.xlsx`, `.xls`, `.csv`, `.doc`, `.docx`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.tiff`, `.heic`, `.zip`, `.tar`, `.gz`
- Check for blocked filenames: `taxpayer_profile.json`, `result.json`, `tax_law_*.json`

Fails if any sensitive file type is found in the PR.

**Why duplicate the pre-commit check?** The pre-commit hook runs locally and can be bypassed with `--no-verify`. CI is the server-side safety net — it catches anything the local hook missed.

### Job 3: `security` — pip-audit

- Checkout repo
- Set up Python 3.12
- Install dependencies
- Run `pip-audit -r requirements.txt`

Fails if any known vulnerability is found in pinned dependencies.

## Dependabot: `.github/dependabot.yml`

- Monitors `pip` ecosystem
- Checks weekly (Sundays)
- Opens PRs for outdated/vulnerable dependencies
- Passive — consumes no CI minutes

## Merge Blocking

By convention only. GitHub Free plan does not support required status checks on private repos. CLAUDE.md will document: "All three CI checks must pass before merging."

## Cost

- Linux runners: 2,000 free minutes/month on Free plan
- Each job: ~30-60 seconds
- At ~10 PRs/month: ~5-10 minutes total — negligible
