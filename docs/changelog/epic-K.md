# Epic K — Integrity round-out

> Detailed per-PR / per-Codex-round implementation history distilled out of `CLAUDE.md` (item O1). The load-bearing invariants remain in `CLAUDE.md`; this file preserves the how-we-got-here narrative and the refuted-vs-fixed review record.

the Epic K integrity round-out — K1 the /tax-verify override hardening (user-declared manual overrides are no longer silently dropped from the discrepancy report — they move to a dedicated `OVERRIDDEN (unverified)` section with the software value / computed value / $ delta / stated reason, excluded from the ERROR count but kept visible since an overridden line is a self-declared departure a reviewer must scrutinize; Step 1.5 + Step 2 + the Step 4 report format + the Step 6 summary all updated) + K2 tax-law source pinning in `tax_law_fetcher.py` (new top-level `_sources` block mapping block-path → authoritative fetch URL; `verify_source_pinning` + `_source_host_authoritative` accept ANY `.gov` host (the TLD is CISA-restricted to bona-fide US government entities, so this covers every federal agency AND every state tax authority — irs.gov, tax.ny.gov, nj.gov, ftb.ca.gov, revenue.wi.gov — without enumerating 50 states) plus an explicit non-`.gov` legal-source set (`law.cornell.edu`); a `.gov` lookalike resolves to a non-`.gov` host (`irs.gov.evil.com` → `.com`) and is rejected; a RECORDED non-authoritative URL → INCOMPLETE (a non-primary figure affirmatively taints the return), a populated-but-unpinned core block → advisory `unpinned_sources` that never flips FRESH so legacy caches pass; the single cached state is pinned as ONE `state.<code>` block (decoupled source-key vs data-path — not per-field, so a `state.CA` pin is actually credited); malformed `_sources` hard-errors; /tax-setup records the primary URL per block) + K3 the PFIC/Form 8621 tripwire — a MANUAL capability rule (`has_foreign_mutual_funds` → Form 8621) that surfaces the §1291-1298 filing obligation on non-US mutual funds/ETFs (punitive §1291 default, QEF/MTM must be timely) without computing it, wired into the /tax-setup foreign-account interview + /tax-review international check + /tax-fbar §4.5 cross-note, flag-only per the roadmap); Codex round 1 (PR #48, P1+3×P2, all fixed): (a) [P1] the source allowlist rejected legitimate state tax domains (tax.ny.gov) — switched to accepting ANY `.gov` host (registry-restricted to government) so every state authority passes without enumeration; (b) [P2] the state pin is now ONE `state.<code>` block (was iterating the state's field keys → bogus state.code/state.name/state.brackets advisories that never credited the real `state.CA` pin); (c) [P2] /tax-verify PASS is UNAVAILABLE while any OVERRIDDEN (unverified) line remains (an unreconciled override could otherwise yield PASS with zero ordinary discrepancies); (d) [P2] the Form 8621 assertion qualified — the obligation is EVENT-DRIVEN (excess distribution / sale / election / §1298(f) annual reporting with de-minimis exceptions), so DETERMINE per fund rather than asserting a blanket per-fund filing); Codex round 2 (PR #48, P2×2, both fixed): (a) the unpinned audit now covers EVERY fetched federal block, not just filing_statuses + capital_gains_rates — `_fetched_federal_blocks` derives them from the schema (a block is fetched-and-filled iff it DIFFERS from its create_empty_tax_law seed), so child_tax_credit/social_security/irmaa/etc. are audited while fully-seeded STRUCTURAL-constant blocks (se_tax/niit/additional_medicare_tax/form_8938_thresholds/ftc_simplified — bill-fixed, template ships complete) and not-yet-fetched blocks (still equal to seed) produce no false advisory; (b) the /tax-setup PFIC question is now asked INDEPENDENTLY of the foreign-account questions — PFIC status follows the FUND's domicile not where it's held, so a foreign-domiciled fund in a US brokerage still sets `has_foreign_mutual_funds`); Codex round 3 (PR #48, P2×3, all fixed): (a) `_source_host_authoritative` now requires an http/https scheme — a gov hostname behind `javascript:`/`file:`/`ftp:` is not a retrievable source and is rejected; (b) `exchange_rates` (IRS yearly-average rates that scale reported USD foreign income / FBAR values) is audited too; (c) the single state block normalizes to the documented `state.<CODE>` pin key via a name→USPS map (a legacy `name: "California"` no-code block no longer emits a bogus `state.California` advisory that a real `state.CA` pin can't satisfy))
